# Contributing to Cloakify

## Getting Started
1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Cloakify.git`
3. Install Python 3.8+ and pytest: `pip install pytest`

## Development
- All code must be Python 3 compatible (Python 2 is not supported)
- Run tests: `python -m pytest tests/ -v`
- Check coverage: `python -m pytest tests/ --cov=.`

## Pull Request Process
1. Ensure all tests pass
2. Add tests for new functionality
3. Update documentation if needed
4. Create a PR with a clear description

## Code Style
- Use 4-space indentation (no tabs)
- Follow PEP 8 guidelines
- Keep scripts standalone and self-contained
